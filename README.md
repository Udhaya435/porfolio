# Udhayakumar S — Full Stack Developer Portfolio

A frontend-only creative developer portfolio built with React, Vite, Tailwind CSS, GSAP (ScrollTrigger & SplitText), Lenis Smooth Scroll, and Lucide React.

## Tech Stack
- **Frontend:** React.js, Vite, JavaScript (ES6+)
- **Styling:** Tailwind CSS, Custom CSS (`src/styles/global.css`, `animations.css`, `responsive.css`)
- **Motion:** GSAP, ScrollTrigger, SplitText, Lenis Smooth Scroll
- **Icons & Typography:** Lucide React, Space Grotesk, Inter

## Local Development

```bash
npm install
npm run dev
```

## Production Build & Preview

```bash
npm run build
npm run preview
```

## Configuration
- Update GitHub and LinkedIn URLs in `src/data/personalInfo.js` (`PERSONAL_INFO.socials`).
- Place your resume PDF at `public/Udhayakumar-Resume.pdf`.
